03 — Architecture

Five Levels — Strict Hierarchy

AOS is not a framework. It is a formal language with five levels. Each level is precisely defined. Each level inherits from the one below.

  • 1
    Objects (3) — NAME / FACT / TARGET

    Atomic carriers of semantics. The irreducible minimum. Every expression begins here.

  • 2
    Expressions

    Composed of three Objects — one coherent unit of meaning.

  • 3
    Sentences

    Expressions invoking Operations — executable meaning.

  • 4
    Dictionaries

    One per User Discipline — the domain vocabulary, organized. The Dictionary IS the Context.

  • 5
    Services

    What Users demand, realized by Operations. The visible output of the system.

The Context Rule — AOS.CONTEXT

An Expression has no absolute meaning. Meaning is relative to the active Dictionary.

interpret(Expression) → SUSPENDED
interpret(Expression, Dictionary) → Operation

The Artifact Rule — JuX.ARTIFACT

Every discipline produces Artifacts. AOS names them. AOS exposes the Artifact directly — no pipeline.

execute(Expression, Dictionary) → Artifact
