## 78 pages. 23 rounds. Zero frameworks. Pure HTML + CSS + JS.

I'm a 60-year-old self-taught developer from Rennes, France. Over three sessions, I built an entire web ecosystem from scratch — no React, no Next.js, no Tailwind, no build tools. Just raw HTML, CSS, and vanilla JavaScript.

### What I Built

**🎮 JuX ARCADE** — A full gaming platform with 6 browser games:
- 🐍 SNAKE — Classic with power-ups
- 🎲 YAMS — Dice game with scoring
- 🃏 HOLD'EM TRAINING — Poker trainer (EN + AR)
- 🎰 MONOPOLY — 9×9 board, Freedom Fighters edition
- 🔮 DUNE TAROT — 79-card mystical deck (3 versions)

**Plus the entire ecosystem:**
- 🎪 Cinematic boot sequence with Web Audio
- ⚔️ Tournament mode (2-8 players, bracket system)
- 🏆 Hall of Fame with 48 prizes
- 📊 Stats dashboard with rank progression
- 🎫 Shareable challenge cards (canvas → PNG)
- 🎵 Ambient synth radio (Web Audio API)
- 🎰 Daily rewards with 7-day streaks
- 🗺️ Interactive star map (constellation navigation)
- 🎬 Auto-playing cinematic trailer

**🧆 Ali Baba's Cavern** — Iraqi-Kurdish grocery store with 17 products and Stripe payments

**📖 SSS** — Soft Sex Story — literary fiction with Dune mythology

**⚙️ AOS** — Adequate Operating System — a formal language architecture (MIT licensed)

### Key Features (Zero Dependencies)

- **PWA** — installable, works offline (service worker + manifest)
- **Web Audio API** — 7 synthesized sounds, no audio files
- **Canvas API** — challenge card generator, constellation map
- **localStorage** — persistent scores, achievements, daily streaks
- **JSON-LD** — structured data for Google (13 products)
- **Stripe** — 10 live payment links, legal footers on all pages

### The Philosophy

No frameworks. No build steps. No node_modules. Every page loads in under 1 second. Every page works without JavaScript for core content. The browser is the platform.

I call it **JuX** — and the 7 Facts that drive it are: TRUTH, DEDUCTION, REASON, MOTIVATION, FUNCTIONAL VIEW, SYNTHESIS, PRODUCTION.
