AOS

Adequate Operating System

A formal language architecture. Five levels. Three objects. One rule.

MIT LIVE OPEN
Foundation — The Three Objects
Object 01
NAME
Identity. The atomic carrier of reference. What a thing is called.
Object 02
FACT
Reality. What is true about the NAME. No opinion. No decoration.
Object 03
TARGET
Direction. Dynamic. Operational. How the NAME moves. Second level.
Architecture — Five Levels
1
Objects
NAME  /  FACT  /  TARGET
Atomic carriers of Semantics. The irreducible minimum.
2
Expressions
Composed of three Objects. One coherent unit of meaning.
3
Sentences
Expressions invoking Operations. Executable meaning.
buy(asset)  ·  mortgage(property)  ·  fix(B11)
4
Dictionaries
One per User Discipline. The domain vocabulary, organized.
5
Services
What Users demand. Realized by Operations. The living edge of AOS.
