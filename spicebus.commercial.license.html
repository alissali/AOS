2. Service Description

SpiceBus delivers structured event notifications across two channels: Slack and Email.

Three priority levels:

  • P1 — CRITICAL: All Actors. Immediate.
  • P2 — BUG: Owner notified. Tracked.
  • P3 — DISPATCH: Assigned Actor notified.

SpiceBus operates on the AOS formal language architecture. Each notification is an Expression. Each Expression carries: NAME / FACT / TARGET.
